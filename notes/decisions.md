# 결정 기록

날짜는 작업 날짜입니다. 결정을 바꿀 때는 지우지 말고 아래에 새 줄을 추가하고 이유를 적습니다.

## 2026-10-19 ~ 20

### 앱이 아니라 웹페이지로 만든다
- 이유: 행사장에서 QR을 찍고 바로 열려야 하므로 설치가 필요 없는 형태가 맞습니다. 파일은 HTML, CSS, JS, JSON, 이미지, PDF뿐입니다.

### GitHub Pages 또는 Cloudflare Pages에 올린다 (최종 선택은 보류)
- 둘 다 무료로 정적 사이트를 호스팅합니다. 어느 쪽을 쓸지는 PDF 총 용량과 공개 여부가 정해지면 결정합니다.
- 한도 (작업 시점에 확인한 값, 올리기 전 재확인 필요): GitHub Pages는 게시 사이트 1GB 권장, Cloudflare Pages 무료는 파일 1개 25MiB와 파일 20,000개.
- 어느 쪽이든 그대로 올라가도록 사이트 폴더 이름을 docs로 했습니다. GitHub Pages가 <main 브랜치의 docs 폴더>를 별도 설정 없이 게시할 수 있기 때문입니다.

### 프레임워크와 빌드 과정을 쓰지 않는다
- 이유: 책이 늘어도 books.json만 고치면 되고, 개발 지식이 없어도 열어 볼 수 있습니다. 도구 업데이트나 빌드 실패로 행사 직전에 깨질 위험도 없습니다.

### 책 정보는 코드 밖(data/books.json)에 둔다
- 시안 단계에서는 데이터가 JS 안에 있었으나, 70권으로 늘면 코드를 건드리지 않고 데이터만 고칠 수 있어야 해서 분리했습니다.
- 대신 file://로는 열리지 않고 로컬 서버가 필요합니다.

### 화면은 사용자가 준 목업 이미지를 기준으로 한다
- 첫 시안(v1)은 목업과 스타일이 많이 달라 사용자가 지적했고, 목업의 색, 글꼴, 일러스트, 창 모양, 문구를 따라 v2로 다시 만들었습니다.
- 문구는 목업 그대로 씁니다. 상단 일러스트, 책더미, 아이콘 4개는 목업 이미지에서 잘라 쓴 것이라 임시입니다 (원본 일러스트 파일이 오면 교체).

### 웹용 PDF는 줄이고 인쇄용 재단선은 가린다
- 샘플 5개를 43.3MB에서 약 14.5MB로 줄였습니다 (이미지 해상도 130dpi 이하로 낮춤, JPEG 화질 75, 텍스트와 도형은 그대로).
- 인쇄용 재단선(크롭 마크)은 PDF의 TrimBox를 기준으로 화면 영역(CropBox)을 잘라 가렸습니다. 원본 내용은 지우지 않고 보이는 영역만 줄인 것입니다.
- 원본은 회사 NAS에 두고, 이 저장소에는 웹용만 올립니다.
- 미검증: 학생용 활동지를 선생님이 인쇄해서 쓸 경우 130dpi 압축본의 인쇄 품질. open-questions.md 참고.

### 상세 화면에 책별 주소는 만들지 않는다
- 지금은 QR이 첫 화면으로만 연결됩니다. 책별 QR이나 링크 공유가 필요해지면 그때 주소 방식(#book=id 등)을 추가합니다. 아직 요청받지 않았습니다.

### 용량 추정
- 샘플 5개 평균은 약 2.9MB입니다. 140개로 단순 환산하면 약 400MB입니다. 표본이 5개뿐이고 파일마다 편차(1.4MB ~ 7.3MB)가 커서 확정치가 아니라 추정입니다. 실제 파일을 모으면 다시 계산합니다. (여기 적은 MB는 모두 1MB = 100만 바이트 기준입니다)

## 2026-10-20 (뜨인돌 미팅 이후)

- 사용자 결정. 사이트(목록판)는 GitHub Pages, PDF와 한글 파일(서고)은 뜨인돌이 준 구글 드라이브 폴더에 둔다.
- 책마다 <화면으로 보기>(줄인 PDF)와 <인쇄용 원본 받기>(드라이브 원본), 한글 파일이 있으면 <한글 파일 받기> 버튼. 코드 반영은 아직.
- QR, 뜨인돌 홈페이지 버튼, 링크트리는 모두 사이트 주소 하나를 가리킨다.
